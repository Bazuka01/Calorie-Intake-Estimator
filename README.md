# Calorix
Your nutrition, simplified.

Calorix is a full-stack web application that helps users estimate their daily calorie needs and explore nutrition information based on their personal goals and activity level.

## Features
- Calculate estimated daily calorie intake
- Calculate Basal Metabolic Rate (BMR)
- Calculate Total Daily Energy Expenditure (TDEE)
- Support for multiple activity levels
- Weight loss, maintenance, and weight gain goals
- Personalized calorie recommendations based on user goals
- Nutrition search powered by the USDA FoodData Central API
- View calories, protein, carbohydrates, fat, and fiber for food results
- High-protein, low-carb, and low-fat food filters
- Goal-based food recommendations
- Calculation history
- Light and dark mode
- Input validation
- Responsive user interface

## How It Works
Users enter their age, gender, weight, height, activity level, and fitness goal.

Calorix uses the Mifflin-St Jeor equation to estimate BMR and calculates TDEE using the user's selected activity level. The recommended calorie intake is then adjusted according to the user's selected goal.

The Nutrition Finder allows users to search for foods using the USDA FoodData Central API and view nutritional information including calories, protein, carbohydrates, fat, and fiber.

Users can also sort search results based on nutritional priorities such as high protein, low carbohydrates, or low fat.
